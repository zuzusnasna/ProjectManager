# 1. Troubleshooting - Spring Boot 8080 포트 충돌

## 1. 문제 상황

Spring Boot 애플리케이션을 실행했을 때 다음 오류가 발생했다.

```
Web server failed to start. Port 8080 was already in use.
```

Spring Boot의 기본 포트인 `8080`을 이미 다른 프로세스가 사용하고 있어 애플리케이션이 서버를 시작하지 못했다.

---

## 2. 원인 확인

Windows CMD에서 8080 포트를 사용 중인 프로세스를 확인했다.

```cmd
netstat -ano | findstr :8080
```

확인 결과:

```
TCP    0.0.0.0:8080    0.0.0.0:0    LISTENING    25480
TCP    [::]:8080       [::]:0       LISTENING    25480
```

마지막 숫자인 `25480`은 해당 프로세스의 PID(Process ID)이다.

해당 PID가 어떤 프로그램인지 확인했다.

```cmd
tasklist | findstr 25480
```

결과:

```
java.exe    25480    Console    2    276,420 K
```

즉, 다른 Java 프로세스가 8080 포트를 사용하고 있었다.

---

## 3. 해결 방법

해당 Java 프로세스를 종료했다.

```cmd
taskkill /PID 25480 /F
```

이후 다시 8080 포트를 확인했다.

```cmd
netstat -ano | findstr :8080
```

더 이상 8080 포트를 사용하는 프로세스가 나타나지 않는 것을 확인했다.

그 후 Spring Boot 애플리케이션을 다시 실행하여 정상적으로 서버가 시작되는 것을 확인했다.
